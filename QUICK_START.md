# Quick Start Guide

## 🚀 Professional Video Production Prompts in Minutes

### Option 1: CLI Launcher (Easiest!)

1. **Run the launcher:**
   ```bash
   python video_prompt_launcher.py
   # or if executable: ./video_prompt_launcher.py
   ```

2. **Choose your mode:**
   - Type `1` for Professional Mode (high-end production prompts)
   - Type `2` for Comedy Mode (absurd, hilarious prompts)
   - Type `3` to Exit

3. **Follow the prompts** to generate your video!

### Option 2: Web Interface ⭐ RECOMMENDED (No Install Required)

1. **Open the file:**
   - Double-click `video-prompt-generator.html`
   - It opens in your browser - that's it!

2. **Choose your mode:**
   - Select "Professional Mode" or "Comedy Mode" from the Generator Mode dropdown
   - The interface updates to show relevant examples

3. **Try it out:**
   - Click "Load example" to fill in sample ideas
   - Click "✨ Generate Prompt"
   - See the magic happen!

4. **Use it for real:**
   - Select "Anthropic (Claude)" or "OpenAI (GPT-4)"
   - Get an API key (see below)
   - Paste your API key
   - Start generating!

**Both modes available in the web interface!** Just switch between them with the dropdown.

### Option 3: Direct CLI (Advanced)

```bash
# Install dependencies
pip install anthropic
# or
pip install openai
# or
pip install xai-sdk

# Professional mode
python video_prompt_cli.py

# Comedy mode
python video_prompt_comedy.py

# Or use the launcher
python video_prompt_launcher.py
```

## 🔑 Getting Your API Key (2 minutes)

### For Anthropic Claude (Recommended):
1. Go to: https://console.anthropic.com/
2. Sign up or log in
3. Go to "API Keys" in settings
4. Click "Create Key"
5. Copy it and paste into the tool

### For OpenAI GPT-4:
1. Go to: https://platform.openai.com/api-keys
2. Sign up or log in
3. Click "Create new secret key"
4. Copy it and paste into the tool

## 💡 What to Enter

Brief, clear bullet points about your video concept:

**Commercial Example:**
```
- Tech startup commercial
- Showcasing innovation and collaboration
- Modern office with natural lighting
- Diverse team working together
- Aspirational yet authentic tone
- 30 seconds, high production value
```

**Narrative Example:**
```
- Short film opening scene
- Character discovers something unexpected
- Moody, mysterious atmosphere
- Urban setting at dusk
- Handheld, intimate camera style
```

**Documentary Example:**
```
- Interview-based documentary segment
- Expert discussing climate solutions
- Natural, authentic feel
- Outdoor setting with environmental context
- 60 seconds, editorial style
```

The tool transforms these into complete production prompts with:
- Professional camera specifications and lens choices
- Detailed lighting design and techniques
- Character/subject direction and blocking
- Shot-by-shot action sequences
- Dialogue and audio design
- Color grading and post-production specs
- Industry-standard terminology throughout
